# Redesign-before-buy canvas (hartwell-kit template, Chapter 11)

Fill one canvas per process before any vendor demo. One page. Synthetic example values belong in the book, not here.

| Box | What goes in it |
|---|---|
| 1. Process and owner | Process name, Line step ID, the named process owner |
| 2. The decisive step | The one step that changes something for a person; quote the Line row |
| 3. Line placement | Side and mode ceiling from `line.place()`, with the five answers |
| 4. Work around the step | Every step before and after it: what is read, drafted, written, and by whom today |
| 5. Hours today | Hours per month on each step, from the time study or ticket data (Chapter 10) |
| 6. Redesign | The steps after redesign: which are removed, which become a rule, which an agent drafts, which stay with the person |
| 7. What the person sees | What the affected employee or candidate is told, and the appeal path from the register |
| 8. Tool requirement | Only now: what a tool must do, at which mode, through which controlled action |
| 9. Measure | The number that shows the redesign worked, who measures it, on what records, over what period |
| 10. Sign-off | Process owner, employment counsel, employee representative where one exists, date, Line version |
